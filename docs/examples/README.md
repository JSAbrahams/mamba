# 5 🧮 Worked Examples

A few small mathematical results, first written in Python, then in Mamba, to get a feel for how the two compare.

## Contents

### [5.1 Euclidean Algorithm (GCD)](euclidean_gcd.md)

A function that genuinely fits Mamba's `total` model:
A single argument that provably decreases.

### [5.2 The Collatz Conjecture](collatz_conjecture.md)

A function almost identical in shape that provably *cannot* be marked `total`, for a reason that has nothing to do with Mamba's checker being weak.

### [5.3 A Busy Beaver](busy_beaver.md)

A step further than Collatz: not just an unproven termination question, but a value that is proven impossible to compute in general.
